> 高频面试题，可以串联计网的各种知识。

- 输入URL并解析
	- 输入URL后，浏览器会解析出协议、主机、端口、路径等信息，并构造一个HTTP请求。(浏览器会根据请求头判断是否有HTTP缓存，并根据是否有缓存决定从服务器获取资源还是使用缓存资源)
- DNS域名解析
	- 发送HTTP请求前，浏览器需要访问网页对应的IP地址，IP地址通过DNS域名解析获取
- 建立TCP连接
	- 客户端和服务器进行HTTP请求和响应需要通过TCP连接，TCP需要进行三次握手
- 浏览器发送HTTP请求到Web服务器
- 服务器处理HTTP请求并返回HTTP报文
	- 服务器会接受请求并将其传递给请求处理程序，并发送HTTP响应，响应一般包含：请求的网页及状态码，压缩类型，如何缓存页面，设置的cookie等
- 浏览器解析并渲染页面
- 断开TCP连接
