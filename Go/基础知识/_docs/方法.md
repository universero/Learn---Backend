## 方法声明

在函数名前加上一个变量就是一个方法，这个方法会被附加到这种类型上。和其余面向对象语言的方法类似。
```go
func (c Class) function() {}
```
附加的参数称作方法的接收器（receiver），类似于其他语言的this或self，但对命名没有限制，通常使用类型的第一个字母
同一类型的方法名称必须唯一，不能像C等语言一样进行函数重载

## 基于指针对象的方法

如果需要更新变量的值，或者参数比较大希望避免拷贝时，通常使用`*Class`方式
一般一个类中有一个方法需要使用指针接收器，那么所有的方法都应该使用指针接收器，即使不需要修改变量
使用指针接收器时，不需要显式的获取对象指针如`(&p).Func()`，编译器会隐式的执行这个方法

有些方法是支持nil的状态的，不过需要做好处理避免出现空指针异常
