## 函数声明

函数声明包括函数名，参数列表， 返回值列表（可选）以及函数体
函数签名则是除了函数体以外的其他内容，函数签名用于判断函数的类型
函数只可判断是否为nil，不可比较

## 多返回值

返回值列表中可以有多个返回值，能够同时给多个变量赋值，或者作为函数的传入参数， 可以减少不少不必要的代码

一般是否成功或是否存在异常通过在返回值列表最后加一个额外的bool类型或者error类型
## 函数值

在Go中函数作为第一类值，拥有类型也可以赋值给其他变量，亦或者作为参数在函数中传入或返回。
函数类型的零值是nil， 执行nil的函数会导致panic。函数值之间不可以比较，也不能作为map的key
## 匿名函数

匿名函数是没有名称的函数，在使用到时才定义。通过匿名函数可以访问完整的词法环境，从而实现闭包的效果。示例如下
```go
// squares返回一个匿名函数。
// 该匿名函数每次被调用时都会返回下一个数的平方。
func squares() func() int {
    var x int
    return func() int {
        x++
        return x * x
    }
}
func main() {
    f := squares()
    fmt.Println(f()) // "1"
    fmt.Println(f()) // "4"
    fmt.Println(f()) // "9"
    fmt.Println(f()) // "16"
}
```
这个例子也说明了函数值不仅仅只是一段代码，还记录了状态；变量的生命周期并不是其作用域决定。

匿名函数也常用于递归场景，如深搜、广搜等
## 可变参数

可变参数可以让函数接收任意个数的参数，在声明可变参数时只需要在类型前加上`...`
可变参数的实现本质上是调用者隐式创建一个数组，并将原始参数移动到数组中，再将参数传给被调用函数。
如果原始参数已经是切片，只需要在传参时加上在变量名后加上`...`就可以实现将切片拆解为多个参数传入
## defer

在函数前加上defer就可以实现延时调用的效果，常用于资源释放等。defer实际的执行时间在return语句更新完返回值变量之后
defer函数的执行顺序与声明顺序相反，类似于栈的形式

不建议在循环中使用defer，只有函数运行到return位置才会开始执行defer，所以可能导致占用过多的文件描述符等资源

defer可以对返回值进行修改
