## 接口类型

接口类型是一种抽象的类型，是支持的操作的集合（不包括内部属性），可以和struct一样通过组合来扩展。接口内部只能定义方法，不能定义属性，且接口不负责方法的实现

当一个struct拥有接口需要的所有的方法时，就认为这个struct实现了这个接口
## 接口值

接口值由接口的类型和接口的值组成，接口的零值就是类型和值都是nil。一个接口值是否为空通过和nil比较判断，当类型和值都为nil时才会相等，调用空接口上的任意方法都会panic
接口值之间可以比较，当且仅当都为nil或者类型（可比较）和当前值都相同时两个接口值相等。如果两个接口的类型相同但不可比较则比较时会panic
## 类型断言

类型断言`x.(T)`是一个使用在接口值上的操作，用于检查他操作的对象和动态是否和断言的类型匹配。如果成功了则会得到这个类型下的x的值，如果失败了则会panic

如果T是一个接口类型，x是一个类型，则会检查x的类型是否满足T，如果成功则则会得到一个接口，如果失败了则panic

断言可以用在类型分支中
```go
switch x.(type) {
case nil:       // ...
case int, uint: // ...
case bool:      // ...
case string:    // ...
default:        // ...
}
```
