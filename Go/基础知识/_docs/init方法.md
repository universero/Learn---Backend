在go语言中，init是个特殊的方法，用于包的初始化工作。在程序启动时自动调用，无需手动触发。

```go
func init() {
  // init主要逻辑
}
```

## 基本特性

- 无参数且无返回值: 没有入参，也没有返回值
- 隐式调用: 由Go运行时自动调用，用户代码不能显式调用init
- 多定义支持: 同一个包或源文件可以定义多个init函数
- 包级别初始化: 每个包的init函数仅执行一遍

## 执行顺序与规则

- 包导入与初始化顺序
	- 依赖优先: 如果包A导入包B，则B的init函数优先于A的init函数执行
- 同一包执行顺序
	- 全局变量初始化优先于init
	- 多个init执行顺序: 按代码出现顺序从上到下执行
	- 不同文件中, 执行顺序与文件名的字典序相关，但**不应该依赖此行为**

## 常见使用场景

- 初始化全局变量
- 注册组件
- 单次检查或配置
