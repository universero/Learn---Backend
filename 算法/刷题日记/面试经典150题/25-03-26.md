## #good 172. 阶乘后的零

### 题目描述

给定一个整数 `n` ，返回 `n!` 结果中尾随零的数量。
### 题解

```go
func trailingZeroes(n int) (ans int) {
    for n > 0 {
        n /= 5
        ans += n
    }
    return
}
```

## 139. 单词拆分

### 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。
### 题解

```go
func wordBreak(s string, wordDict []string) bool {
	n := len(s)
	can := make(map[string]bool)
	for _, word := range wordDict {
		can[word] = true
	}
	dp := make([]bool, n+1, n+1)
	dp[0] = true
	for i := 1; i <= n; i++ {
		for j := 0; j < i; j++ {
			if dp[j] && can[s[j:i]] {
                dp[i] = true
                break
			}
		}
	}
    return dp[n]
}
```

- 没写过类似的, 没什么思路, dp的作用主要是记录状态，所以一般都是遍历一个有序的对象去判断最终情况

## 322. 零钱兑换

### 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

### 题解

```go
func coinChange(coins []int, amount int) int {
	max := amount + 1
	dp := make([]int, amount+1, amount+1)
	for i := 0; i < amount+1; i++ {
		dp[i] = max
	}
	dp[0] = 0
	for i := 1; i <= amount; i++ {
		for j := 0; j < len(coins); j++ {
			if coins[j] <= i {
				dp[i] = min(dp[i], dp[i-coins[j]]+1)
			}
		}
	}
	if dp[amount] > amount {
		return -1
	}
	return dp[amount]
}
```

### 问题记录

- 依旧完全没有想法🤣
- dp需要遍历的应该是最终的目标，如本题是需要凑成的钱数
- 每一步的状态转移的过程可能是复杂的，不一定有一个明确的方程，而是一个过程
