## 49. 字母异位词分组

### 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。
### 题解

```go
func groupAnagrams(strs []string) [][]string {
    sortedStrs := sortS(strs)
    m := make(map[string][]string)
    for i := range sortedStrs {
        if _, ok := m[sortedStrs[i]]; !ok {
            m[sortedStrs[i]] = make([]string, 0)
        }
        m[sortedStrs[i]] = append(m[sortedStrs[i]], strs[i])
    }
    ans := make([][]string, 0)
    for _, v := range m {
        ans = append(ans, v)
    }
    return ans
}
  
func sortS(strs []string) []string {
    ans := make([]string, 0)
    for _, v := range strs {
        // 将字符串转换为rune切片
        runes := []rune(v)
        // 创建rune切片的副本
        sortedRunes := make([]rune, len(runes))
        copy(sortedRunes, runes)
        // 对副本进行排序
        sort.Slice(sortedRunes, func(i, j int) bool {
            return sortedRunes[i] < sortedRunes[j]
        })
        // 将排序后的rune切片转换回字符串
        ans = append(ans, string(sortedRunes))
    }
    return ans
}
```

## 1. 两数之和

### 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。
### 题解

```go
func twoSum(nums []int, target int) []int {
    m := make(map[int]int)
    for i,v := range nums {
        need := target - v
        if j,ok := m[need];ok {
            return []int{i,j}
        }
        m[v] = i
    }
    return nil
}
```

## 202. 快乐数

### 题目描述

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是 _快乐数_ 就返回 `true` ；不是，则返回 `false` 。

### 题解

```go
func isHappy(n int) bool {
    visit := make(map[int]bool)
    if n == 1 {
        return true
    }
    for n!=1 {
        nums := parse(n)
        tmp := 0
        for _,v := range nums {
            tmp += v*v
        }
        if tmp == 1 {
            return true
        }
        if _,ok:=visit[tmp];ok {
            break
        }
        visit[tmp] = true
        n = tmp
    }
    return false
}
  
func parse(n int) []int {
    ans := make([]int,0)
    for n>0 {
        ans = append(ans,n%10)
        n = n/10
    }
    return ans
}
```
