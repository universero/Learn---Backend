## 3. 无重复字符的最长子串

### 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度
### 题解

```go
func lengthOfLongestSubstring(s string) int {
	l,r := 0, 0
	m := make(map[byte]bool)
	ans := 0
	for ;r < len(s);r++ {
        for m[s[r]] == true {
            m[s[l]] = false
            l++
        }
        m[s[r]] = true
        ans = max(r-l+1,ans)
	}
	return ans
}

func max(a,b int) int {
	if a > b {
		return a
	}
	return b
}
```

### 问题记录

- `s[r]`取出来的是一个byte类型，不能直接将其作为rune的key
- `s[r]=='D'`这种操作时能隐式转换类型，但是作为map的key时不能隐式转换，必须严格匹配
