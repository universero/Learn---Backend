## 11. 盛最多水的容器

### 题目描述

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

### 题解

```go
func maxArea(height []int) int {
	l,r := 0, len(height)-1
	ans := 0
	for l < r {
		tmp := min(height[l],height[r]) * (r - l)
		if (tmp > ans) {
			ans = tmp
		}
		if height[l] > height[r] {
			r--
		}else {
			l++
		}
	}
	return ans
}

func min(l,r int) int{
	if l >= r {
		return r
	}
	return l
}
```

## 15. 三数之和

### 题目描述

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。
### 题解

```go
func threeSum(nums []int) [][]int {
    n := len(nums)
    sort.Ints(nums)
    ans := make([][]int, 0)
    for fir := 0; fir < n-2; fir++ {
        // 跳过可能重复的元素
        if fir > 0 && nums[fir] == nums[fir-1] {
            continue
        }
        sec := fir + 1
        thi := n - 1
        for sec < thi {
            tmp := nums[fir] + nums[sec] + nums[thi]
            if tmp > 0 {
		        thi--
            } else if tmp < 0 {
                sec++
            } else {
                ans = append(ans, []int{nums[fir], nums[sec], nums[thi]})
                for sec < thi && nums[sec] == nums[sec+1] {
                    sec++
                }
                for sec < thi && nums[thi] == nums[thi-1] {
                    thi--
                }
                sec++
                thi--
            }
        }
    }
    return ans
}
```

### 问题记录

- 没有理解题意，ans中直接放了fir、sec、thi
- ans增加一组答案时忘记移动sec和thi导致一直添加，内存溢出
- 没有考虑到去除重复元素，以及如何去除重复元素

### 知识点

- sort.Inst(num) 将切片原地升序排序
- sort.Sort(sort.Reverse(sort.IntSlice(nums))), 降序

## 209. 长度最小的子数组

### 题目描述

给定一个含有 `n` 个正整数的数组和一个正整数 `target` **。**

找出该数组中满足其总和大于等于 `target` 的长度最小的 **子数组** `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度**。**如果不存在符合条件的子数组，返回 `0` 。
### 题解

```go
func minSubArrayLen(target int, nums []int) int {
	l, r := 0, 0
	sum := 0
	ans := 0
	for r < len(nums) {
		sum += nums[r]
		for sum >= target {
			if ans == 0 {
				ans = r - l + 1
			} else if ans > r-l+1 {
				ans = r - l + 1
			}
            sum -=nums[l]
            l++
		}
		r++
	}
	return ans
}
```

### 问题记录

- 排序方法错误，应该是sort.Sort(sort.Reverse(sort.IntSlice(nums)))，而不是sort.Ints(sort.Reverse(nums))
- 题意理解错误，是子数组，所以不应该排序
- 转用贪心，左右两个指针向内靠近，但是忽略了无序性，导致可能忽略最优解
- 使用滑动窗口，每次都加到符合target，然后移动l靠近r，这样就不会错过最优解
