## #good 71. 简化路径

### 题目描述

给你一个字符串 `path` ，表示指向某一文件或目录的 Unix 风格 **绝对路径** （以 `'/'` 开头），请你将其转化为 **更加简洁的规范路径**。

在 Unix 风格的文件系统中规则如下：

- 一个点 `'.'` 表示当前目录本身。
- 此外，两个点 `'..'` 表示将目录切换到上一级（指向父目录）。
- 任意多个连续的斜杠（即，`'//'` 或 `'///'`）都被视为单个斜杠 `'/'`。
- 任何其他格式的点（例如，`'...'` 或 `'....'`）均被视为有效的文件/目录名称。

返回的 **简化路径** 必须遵循下述格式：

- 始终以斜杠 `'/'` 开头。
- 两个目录名之间必须只有一个斜杠 `'/'` 。
- 最后一个目录名（如果存在）**不能** 以 `'/'` 结尾。
- 此外，路径仅包含从根目录到目标文件或目录的路径上的目录（即，不含 `'.'` 或 `'..'`）。

返回简化后得到的 **规范路径** 。
### 题解

```go
func simplifyPath(path string) string {
    // 结尾统一/ 方便处理
    if path[len(path)-1] != '/' {
        path += "/"
    }
    s := make([]string, len(path), len(path))
    top := 0
    s[top] = "/"
    top++
    tmp := ""
    for _, v := range path {
        if v == '/' {
            if tmp == "" || tmp == "/" {
                continu
            }
            s[top] = tmp
            top++
            s[top] = "/"
            top++
            tmp = ""
        } else {
            tmp += string(v)
        }
    }
    // 去除掉统一添加的结尾/
    top--
    ans := ""
    for top > 0 {
        tmp = s[top-1]
        top--
        if tmp == "." {
            top--
        } else if tmp == ".." {
            top -= 3
        } else {
            ans = tmp + ans
        }
    }
    n := len(ans)
    if n == 0 {
        return "/"
    } else if n > 1 && ans[n-1] == '/' {
        return ans[:len(ans)-1]
    }
    return ans
}
```

### 知识点

```go
func simplifyPath(path string) string {
    stack := []string{}
    for _, name := range strings.Split(path, "/") {
        if name == ".." {
            if len(stack) > 0 {
                stack = stack[:len(stack)-1]
            }
        } else if name != "" && name != "." {
            stack = append(stack, name)
        }
    }
    return "/" + strings.Join(stack, "/")
}
```

- strings.Split(string, "/")按照指定的字符串将字符串分割成切片
- strings.Join(切片,"/")按照指定的字符串拼接切片
- 这题如果希望简化操作就不应该考虑/，原来就是因为考虑了/导致很复杂还不好处理，不考虑/只考虑目录名的话就可以按照语义操作了。.的话就不需要加如栈，因为没变化，..的话就出栈一个得到父目录
## #good 155. 最小栈

### 题目描述

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。
### 题解

```go
type MinStack struct {
    stack    []int
    minStack []int
}
  
func Constructor() MinStack {
    return MinStack{
        stack:    []int{},
        minStack: []int{math.MaxInt64},
    }
}
  
func (this *MinStack) Push(val int) {
    this.stack = append(this.stack, val)
    m := this.minStack[len(this.minStack)-1]
    this.minStack = append(this.minStack, min(val, m))
}
  
func (this *MinStack) Pop() {
    this.stack = this.stack[:len(this.stack)-1]
    this.minStack = this.minStack[:len(this.minStack)-1]
}
  
func (this *MinStack) Top() int {
    return this.stack[len(this.stack)-1]
}
  
func (this *MinStack) GetMin() int {
    return this.minStack[len(this.minStack)-1]
}

func min(a, b int) int {
    if a > b {
        return b
    }
    return a
}
```

### 问题记录

- 起初的想法是维护一个额外的单调链表，每次出栈时删除掉对应的节点，这样的话删除确实好维护，只需要每个元素额外记录一下对应的节点，删除时前驱节点指向后继就行。但是插入的话需要O(n)找到合适的位置插入
- 题解的思路是用一个额外的栈来维护，在一个元素出栈前，最小值只能是这个元素或者这个元素前的最小值(有点动态规划的意思?)这样只需要入栈的时候维护一下最新入栈位置的最小值即可

## 逆波兰表达式求值

### 题目描述

给你一个字符串数组 `tokens` ，表示一个根据 [逆波兰表示法](https://baike.baidu.com/item/%E9%80%86%E6%B3%A2%E5%85%B0%E5%BC%8F/128437) 表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

**注意：**

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'` 。
- 每个操作数（运算对象）都可以是一个整数或者另一个表达式。
- 两个整数之间的除法总是 **向零截断** 。
- 表达式中不含除零运算。
- 输入是一个根据逆波兰表示法表示的算术表达式。
- 答案及所有中间计算结果可以用 **32 位** 整数表示。

### 题解

```go
func evalRPN(tokens []string) int {
    stack := []int{}
    for _, v := range tokens {
        switch v {
        case "+":
            num2 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            num1 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            stack = append(stack, num1+num2)
        case "-":
            num2 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            num1 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            stack = append(stack, num1-num2)
        case "*":
            num2 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            num1 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            stack = append(stack, num1*num2)
        case "/":
            num2 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            num1 := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            stack = append(stack, num1/num2)
        default:
            stack = append(stack, atoi(v))
        }
    }
    return stack[len(stack)-1]
}
  
func atoi(s string) (num int) {
    negative := 1
    i := 0
    if s[i] == '-' {
        i++
        negative = -1
    }
    num = 0
    for ;i < len(s);i++ {
        num = num*10 + int(s[i]) - int('0')
    }
    return num * negative
}
```

- 第一次提交时忘记考虑负数

### 知识点

```go
func evalRPN(tokens []string) int {
    stack := []int{}
    for _, token := range tokens {
        val, err := strconv.Atoi(token)
        if err == nil {
            stack = append(stack, val)
        } else {
            num1, num2 := stack[len(stack)-2], stack[len(stack)-1]
            stack = stack[:len(stack)-2]
            switch token {
            case "+":
                stack = append(stack, num1+num2)
            case "-":
                stack = append(stack, num1-num2)
            case "*":
                stack = append(stack, num1*num2)
            default:
                stack = append(stack, num1/num2)
            }
        }
    }
    return stack[0]
}
```

- strconv.Atoi(string)可以将字符串转换为数字，如果失败则返回error
- 用这个可以极大的简化代码，自己写的这个有太多重复代码了
