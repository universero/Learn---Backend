## 2537. 统计好子数组的数目

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回 `nums` 中 **好** 子数组的数目。

一个子数组 `arr` 如果有 **至少** `k` 对下标 `(i, j)` 满足 `i < j` 且 `arr[i] == arr[j]` ，那么称它是一个 **好** 子数组。

**子数组** 是原数组中一段连续 **非空** 的元素序列。

### 题解

```go
func countGood(nums []int, k int) int64 {
	n := len(nums)
	var ans int64 = 0
	// 每个数字出现了几次
	m := make(map[int]int)
	// 满足的对数
	sum := 0
	j := -1
	for i := 0; i < n; i++ {
		for sum < k && j+1 < n {
			j++
			sum += m[nums[j]]
			m[nums[j]]++
		}
		if sum >= k {
			ans += int64(n - j)
		}
		m[nums[i]]--
		sum -= m[nums[i]]
	}
	return ans
}
```

## 63. 不同路径 II

### 题目描述

给定一个 `m x n` 的整数数组 `grid`。一个机器人初始位于 **左上角**（即 `grid[0][0]`）。机器人尝试移动到 **右下角**（即 `grid[m - 1][n - 1]`）。机器人每次只能向下或者向右移动一步。

网格中的障碍物和空位置分别用 `1` 和 `0` 来表示。机器人的移动路径中不能包含 **任何** 有障碍物的方格。

返回机器人能够到达右下角的不同路径数量。

测试用例保证答案小于等于 `2 * 109`。

### 题解

```go
func uniquePathsWithObstacles(obstacleGrid [][]int) int {
	m := len(obstacleGrid)
	n := len(obstacleGrid[0])
	dp := make([][]int, m)
	for i := range dp {
		dp[i] = make([]int, n)
	}

	dp[0][0] = 1
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			if obstacleGrid[i][j] == 0 {
				if j == 0 && i == 0 {
					dp[i][j] = 1
				} else if j == 0 {
					dp[i][j] = dp[i-1][j]
				} else if i == 0 {
					dp[i][j] = dp[i][j-1]
				} else {
					dp[i][j] = dp[i-1][j] + dp[i][j-1]
				}
			} else {
				dp[i][j] = 0
			}
		}
	}
	return dp[m-1][n-1]
}
```

### 问题记录

如果左上角和右下角在一个点, 而且这里还有障碍就不行了, 所以加了个`else dp[i][j]=0`

## 5. 最长回文子串

### 题目描述

给你一个字符串 s，找到 s 中最长的 回文 子串。
### 题解

```go
func longestPalindrome(s string) string {
	n := len(s)
	if n == 1 {
		return s
	}

	max := 1
	start := 0
	// dp[i][j] 标识i..j是否为回文串
	dp := make([][]bool, n)
	for i := range dp {
		dp[i] = make([]bool, n)
	}
	// 长度1一定是回文串
	for i := 0; i < n; i++ {
		dp[i][i] = true
	}

	// 枚举字串的长度
	for len := 2; len <= n; len++ {
		for i := 0; i < len; i++ {
			j := i + len - 1
			if j >= len {
				break
			}
			if s[i] != s[j] {
				dp[i][j] = false
			} else {
				if j-i < 3 {
					dp[i][j] = true
				} else {
					dp[i][j] = dp[i+1][j-1]
				}
			}
			if dp[i][j] && j-i+1 > max {
				max = j - i + 1
				start = i
			}
		}
	}
	return s[start : start+max]

}
```

### 问题记录

- 核心在于找到状态转移方程, `当i,j值相等时dp[i][j]取决于内部是否为回文串`
### 知识点

- 从中间向两侧扩展可能代码上会更简单点
