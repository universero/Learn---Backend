## 100. 相同的树

### 题目描述

给你两棵二叉树的根节点 `p` 和 `q` ，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

### 题解

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isSameTree(p *TreeNode, q *TreeNode) bool {
	preP := pre(p)
	midP := mid(p)
	preQ := pre(q)
	midQ := mid(q)

	return preP == preQ && midP == midQ
}

func pre(p *TreeNode) string {
    if p == nil {
        return "null"
    }
    s := strconv.Itoa(p.Val)
    s += pre(p.Left)
    s += pre(p.Right)
    return s
}

func mid(p *TreeNode) string {
    if p == nil {
        return "null"
    }
    s := mid(p.Left) 
    s += strconv.Itoa(p.Val) 
    s += mid(p.Right)
    return s
}
```

### 问题记录

`string(p.Val)`，这会将整数 `p.Val` 转换为对应的 Unicode 字符，而不是直接拼接整数的字符串表示。

## 226. 翻转二叉树

### 题目描述

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。
### 题解

```go
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return root
    }
    ir := invertTree(root.Right)
    il := invertTree(root.Left)
    root.Left = ir
    root.Right = il
    return root
}
```

### 问题记录

- 如果没用ir、il直接赋值给left和right会导致第二个是第一个翻转两次，丢失了另一半的节点

## 101. 对称二叉树

### 题目描述

给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

### 题解

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isSymmetric(root *TreeNode) bool {
	if root == nil {
		return true
	}
	if root.Left == nil && root.Right == nil {
		return true
	}
	if root.Left != nil && root.Right != nil {
		return same(root.Left, root.Right)
	}
	return false
}

func same(q, p *TreeNode) bool {
	if q == nil && p == nil {
		return true
	}
	if q == nil || p == nil {
		return false
	}
	if q.Val != p.Val {
		return false
	}
    return same(q.Left,p.Right) && same(q.Right,p.Left)
}
```
