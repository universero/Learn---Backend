## 34. 在排序数组中查找元素的第一个和最后一个位置

### 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题

### 题解

```go
func searchRange(nums []int, target int) []int {
	n := len(nums)
	if n == 0 {
		return []int{-1, -1}
	}
	l, r := 0, n-1
	fir, las := -1, -1

	for l <= r {
		m := (l + r) >> 1
		if nums[m] == target {
			fir = m
			r = m - 1 // 核心
		} else if nums[m] > target {
			r = m - 1
		} else {
			l = m + 1
		}
	}

	l, r = 0, n-1
	for l <= r {
		m := (l + r) >> 1
		if nums[m] == target {
			las = m
			l = m + 1 //  核心
		} else if nums[m] > target {
			r = m - 1
		} else {
			l = m + 1
		}
	}

	return []int{fir, las}
}
```

### 知识点

- 两个标记核心处实现了二分查找找到最左侧或者最右侧的target

## 153. 寻找旋转排序数组中的最小值

### 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：

- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]` 。

给你一个元素值 **互不相同** 的数组 `nums` ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素** 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

### 题解

```go
func findMin(nums []int) int {
	n := len(nums)
	l, r := 0, n-1

	for l <= r {
		m := (l + r) >> 1
		if nums[0] <= nums[m] {
			l = m + 1
		} else {
			r = m - 1
		}
	}
	if l < n && nums[l] < nums[0] {
		return nums[l]
	}
	return nums[0]
}
```

### 问题记录

- 找到右侧有序部分的最小值, 与左侧最小值(index 0)比较即可
- 整个都有序时, l会超出数组范围

## 4. 寻找两个正序数组的中位数

### 题目描述
给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。

算法的时间复杂度应该为 O(log (m+n)) 。

### 题解

```go
func findMedianSortedArrays(nums1 []int, nums2 []int) float64 {
	n, m := len(nums1), len(nums2)
	if (n+m)%2 == 0 {
		return float64((kth(nums1, 0, n-1, nums2, 0, m-1, (n+m+1)/2) + kth(nums1, 0, n-1, nums2, 0, m-1, (n+m+2)/2))) * 0.5
	}
	return float64(kth(nums1, 0, n-1, nums2, 0, m-1, (n+m+1)/2))
}

func kth(nums1 []int, s1, e1 int, nums2 []int, s2, e2, k int) int {
	l1 := e1 - s1 + 1
	l2 := e2 - s2 + 1
	if l1 > l2 {
		// 限制l1为短的数组
		return kth(nums2, s2, e2, nums1, s1, e1,k)
	}
	if l1 == 0 {
		return nums2[s2+k-1]
	}
	if k == 1 {
		return min(nums1[s1], nums2[s2])
	}
	i := s1 + min(l1, k/2) - 1
	j := s2 + min(l2, k/2) - 1
	if nums1[i] > nums2[j] {
		return kth(nums1, s1, e1, nums2, j+1, e2, k-(j-s2+1))
	}
	return kth(nums1, i+1, e1, nums2, s2, e2, k-(i-s1+1))
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
```

### 问题记录

- 求中位数其实是求第k小元素的一种特殊情况
- 每次只需要排除掉k/2的元素, 逐步逼近

### 知识点
