## 128. 最长连续序列

### 题目描述

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。
### 题解

```go
func longestConsecutive(nums []int) int {
    // 将所有的元素加入到set中
    set := make(map[int]struct{})
    for _, num := range nums {
        set[num] = struct{}{}
    }

    res := 0
    for num := range set {
        // 判断是不是第一个元素
        if _, ok := set[num-1]; ok {
            continue
        }
        tmp := 0
        for {
            if _, ok := set[num]; !ok {
               break
            }
            num += 1
            tmp += 1
        }
        if tmp > res {
            res = tmp
        }
    }
    return res
}
```

### 问题记录

-   一开始的想法时，哈希到一个链表，然后如果前一个或者后一个元素存在就加到链表上，理论上来说是没有问题的，但是实现上比较复杂，需要每个元素都映射到他存在的节点上，不过理论上来速度会更快，因为只需要遍历一遍
-   后来觉得实现麻烦就直接看题解了，加入所有元素到set中，再遍历set中的每一个可以作为开头的元素，虽然可能会遍历次数更多，但是实现上简单了很多
### 知识点

- `O(n)`并不一定只是遍历一次，只要是线性的遍历都是`O(n)`

```go
func summaryRanges(nums []int) []string {
    n := len(nums)
    if n == 0 {
        return []string{}
    } else if n == 1 {
        return []string{strconv.Itoa(nums[0])}
    }
    ans := make([]string, 0)
    l, r := 0, 1
    for r <= n {
        if r < n && nums[r] == nums[r-1]+1 {
            r++
        } else {
            if l == r-1 {
                ans = append(ans, strconv.Itoa(nums[l]))
            } else {
                ans = append(ans, strconv.Itoa(nums[l])+"->"+strconv.Itoa(nums[r-1]))
            }
            l = r
            r++
        }
    }
    return ans
}
```

## 56. 合并区间

### 题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回 _一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间_

### 题解

```go
func merge(intervals [][]int) [][]int {
    // 按左边界、右边界的顺序升序排序
    sortedIntervals := sortInterval(intervals)
    // 初始化返回结果
    ans := make([][]int, 0)
    for _, v := range sortedIntervals {
        if len(ans) == 0 {
            ans = append(ans, v)
            continue
        }
        last := ans[len(ans)-1]
        if v[0] > last[1] {
            ans = append(ans, v)
        } else if v[0] <= last[1] && v[1] >= last[1] {
            last[1] = v[1]
        }
    }
    return ans
}
  
func sortInterval(intervals [][]int) [][]int {
    ans := make([][]int, 0)
    for _, v := range intervals {
        ans = append(ans, v)
    }
    sort.Slice(ans, func(i, j int) bool {
        if ans[i][0] == ans[j][0] {
            return ans[i][1] < ans[j][1]
        }
        return ans[i][0] < ans[j][0]
    })
    return ans
}
```

### 问题记录

- 题目逻辑是简单的，但是写着写着就跑去考虑数组的浅拷贝深拷贝了，这个确实需要注意

### 知识点

- sort.Slice能简化很多排序代码的编写，需要记牢
