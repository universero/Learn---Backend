## 77. 组合

### 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按 **任何顺序** 返回答案。

### 题解

```go
func combine(n int, k int) [][]int {
	ans := make([][]int, 0)
	var find func(tmp []int, i int)
	find = func(tmp []int, i int) {
		if len(tmp) == k {
			ans = append(ans, append([]int{}, tmp...))
			return
		}
		for ; i <= n; i++ {
			find(append(tmp, i), i+1)
		}
	}
	find([]int{}, 1)
	return ans
}
```

### 问题记录

- 回溯时，如果ans中不是创建新的数组加进去，而是直接加入tmp，后续tmp的修改会导致底层数组被修改

## 46. 全排列

### 题目描述

给定一个不含重复数字的数组 `nums` ，返回其 _所有可能的全排列_ 。你可以 **按任意顺序** 返回答案。
### 题解

```go
func permute(nums []int) [][]int {
    n := len(nums)
	ans := make([][]int, 0)
	vis := make([]bool,n + 1)
	var backTrace func(tmp []int)
	backTrace = func(tmp []int) {
		if len(tmp) == n {
            t := []int{}
            for _,v := range tmp {
                t = append(t,nums[v-1])
            }
			ans = append(ans, t)
		}
		for i := 1; i <= n; i++ {
			if vis[i] == false {
				vis[i] = true
				backTrace(append(tmp, i))
                vis[i] = false
			}
		}
	}
    backTrace([]int{})
    return ans
}
```

## 39. 组合总和

### 题目描述

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 **不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。 

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

### 题解

```go
func combinationSum(candidates []int, target int) [][]int {
	n := len(candidates)
	ans := make([][]int, 0, 150)
	var backTrace func(i int, tar int, tmp []int)
	backTrace = func(i int,tar int,tmp []int) {
		if tar == 0 {
			ans = append(ans, append([]int{},tmp...))
			return
		}
		for ; i < n; i++ {
			if tar < candidates[i] {
				continue
			}
			backTrace(i, tar-candidates[i], append(tmp, candidates[i]))
		}
	}
    backTrace(0,target,[]int{})
    return ans
}
```

### 知识点

- 回溯的统一模板
```go
func backTrace(可访问路径, 当前路径) {
	if 终止条件 {
		记录结果
		return
	}
	for 可访问路径 {
		选择一条路径
		backTrace(下一步可访问路径，选择后路径)
		撤销选择
	}
}
```
