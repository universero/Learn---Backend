## 2962. 统计最大元素出现至少 K 次的子数组

### 题目描述
给你一个整数数组 `nums` 和一个 **正整数** `k` 。
请你统计有多少满足 「 `nums` 中的 **最大** 元素」至少出现 `k` 次的子数组，并返回满足这一条件的子数组的数目。
子数组是数组中的一个连续元素序列。
### 题解

```go
func countSubarrays(nums []int, k int) int64 {
	var large int
	for _, num := range nums {
		if num > large {
			large = num
		}
	}
	var ans int64
	cnt, l, r, n := 0, 0, 0, len(nums)
	for r < n {
		if nums[r] == large {
			cnt++
		}
		if cnt >= k {
			for l < n && cnt >= k {
				ans += int64(n - r)
				if nums[l] == large {
					cnt--
				}
				l++
			}
		}
		r++

	}
	return ans
}
```
