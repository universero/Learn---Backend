## 2799. 统计完全子数组的数目

### 题目描述
给你一个由 正 整数组成的数组 nums 。
如果数组中的某个子数组满足下述条件，则称之为 完全子数组 ：
子数组中 不同 元素的数目等于整个数组不同元素的数目。
返回数组中 完全子数组 的数目。
子数组 是数组中的一个连续非空序列。

### 题解

```go
func countCompleteSubarrays(nums []int) int {
    res := 0
    cnt := make(map[int]int)
    n := len(nums)
    right := 0
    distinct := make(map[int]bool)
    for _, num := range nums {
        distinct[num] = true
    }
    distinctCount := len(distinct)
    for left := 0; left < n; left++ {
        if left > 0 {
            remove := nums[left-1]
            cnt[remove]--
            if cnt[remove] == 0 {
                delete(cnt, remove)
            }
        }
        for right < n && len(cnt) < distinctCount {
            add := nums[right]
            cnt[add]++
            right++
        }
        if len(cnt) == distinctCount {
            res += (n - right + 1)
        }
    }
    return res
}

```

### 知识点
- 滑动窗口统计窗口内是否满足, 若满足则之后的都满足
- 这种只考虑元素的不同, 不考虑元素数量的时候, 用map的元素数量效率会更高
- delete(map, key)能立即从map中删除元素, 减少map的长度
## 76. 最小覆盖子串

### 题目描述

给你一个字符串 s 、一个字符串 t 。返回 s 中涵盖 t 所有字符的最小子串。如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串 "" 。
**注意：**
- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。
### 题解

```go
func minWindow(s string, t string) string {
	n := len(s)
	m := len(t)
	if n < m {
		return ""
	}

	length := math.MaxInt
	start := -1

	// 统计t和窗口中各字符数
	ct := make(map[byte]int)
	cs := make(map[byte]int)

	// 统计t
	for i := 0; i < m; i++ {
		ct[t[i]] += 1
	}

	// 窗口左右边界
	l, r := 0, 0
	cs[s[r]] += 1

	check := func() bool {
		for k := range ct {
			if ct[k] > cs[k] {
				return false
			}
		}
		return true
	}

	// 滑动窗口
	for l < n && r < n {
		if !check() {
			r++
			if r < n {
				cs[s[r]] += 1
			}
		} else {
			if r-l+1 < length {
				length = r - l + 1
				start = l
			}
			cs[s[l]] -= 1
			if cs[s[l]] == 0 {
				delete(cs, s[l])
			}
			l++
		}
	}

	if start == -1 {
		return ""
	}
	return s[start : start+length]
}
```

### 问题记录

- 这种滑动窗口可以for循环中移动r, 然后如果满足条件就不断通过l缩小窗口, 使得代码简洁点

## 53. 最大子数组和

### 题目描述
给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。
### 题解

```go
func maxSubArray(nums []int) int {
	max := nums[0]
	for i := 1; i < len(nums); i++ {
		if nums[i]+nums[i-1] > nums[i] {
			nums[i] += nums[i-1]
		}
		if nums[i] > max {
			max = nums[i]
		}
	}
	return max
}

// 前缀和
func maxSubArray(nums []int) int {
	// 前缀和
	pre := make([]int, len(nums))
	pre[0] = nums[0]

	n := len(nums)
	for i := 1; i < n; i++ {
		pre[i] = pre[i-1] + nums[i]
	}

	// 遍历过的最小值
	min := pre[0]
	if min > 0 {
		min = 0
	}
	ans := pre[0]
	for i := 1; i < n; i++ {
		if pre[i]-min > ans {
			ans = pre[i] - min
		}
		if pre[i] < min {
			min = pre[i]
		}
	}
	return ans
}
```

### 问题记录
- 一开始想用前缀和, 然后维护一个最小值, 遍历到的和最小值做差. 但是min的维护需要注意的是, 如果第一个数大于0其实不一定需要减去的, 需要对min做一个特殊的判断
