## 283. 移动零

### 题目描述

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意 ，必须在不复制数组的情况下原地对数组进行操作。

 
### 题解

```go
func moveZeroes(nums []int) {
	l, r := -1, 0
	for r < len(nums) {
		if nums[r] != 0 {
			l++
			nums[l], nums[r] = nums[r], nums[l]
		}
		r++
	}
}
```

### 问题记录

### 知识点

- 不修改原顺序的话, 维护两个指针,  一个表示符合条件部分最后的位置, 一个表示遍历到的位置
- 遇到满足条件的就更新符合条件的最后位置

## 11. 盛最多水的容器

### 题目描述

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

### 题解

```go
func maxArea(height []int) int {
	l, r := 0, len(height)-1
	ans := 0
	for l < r {
		ans = max(ans, (r-l)*min(height[l], height[r]))
		if height[l] > height[r] {
			r--
		} else {
			l++
		}
	}
	return ans
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
```

### 问题记录

### 知识点

- 贪心, 维护双指针, 每次必定靠拢, 所以舍弃高度低的项

## 15. 三数之和

### 题目描述

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

### 题解

```go
func threeSum(nums []int) [][]int {
	ans := make([][]int, 0)
	n := len(nums)
	sort.Slice(nums, func(i, j int) bool { return nums[i] < nums[j] })
	for l := 0; l < n-2; l++ {
		if l > 0 && nums[l] == nums[l-1] {
			continue
		}
		m, r := l+1, n-1
		for m < r {
			tmp := nums[m] + nums[r] + nums[l]
			if tmp == 0 {
				ans = append(ans, []int{nums[l], nums[m], nums[r]})
				m++
				r--
				for m < r && nums[m] == nums[m-1] {
					m++
				}
				for m < r && nums[r] == nums[r+1] {
					r--
				}
			}else if tmp > 0 {
				r--
			} else {
				m++
			}
		}
	}
	return ans
}
```

### 问题记录

### 知识点

- 通过`nums[l]==nums[l-1]`时`l++`来避免重复
- 三数和本质上是确定一个数后, 对另外两个数做两数和
