## introduce

- MongoDB是一个C++语言编写的基于分布式文件存储的数据库，旨在为WEB应用提供可扩展的高性能数据存储解决方案
- MongoDB是一个介于关系数据库和非关系数据库之间的产品，支持的数据结构非常松散，是类似json的bson结构，可以存储比较复杂的数据类型
- 查询语法强大，类似于面向对象的查询语言，可以实现关系型数据库单表查询的绝大部分功能，支持对数据建立索引
## 应用场景

MongoDB主要应对三高需求
- High performance 对数据库高并发读写需求
- Huge Storage 对海量数据的高效率存储和访问需求
- High Scalability & High Availablity 对数据库的高可扩展性和高可用性的需求

什么时候选择MongDB
- 应用不需要事务及复杂join支持
- 新应用，需求会变，数据模型无法确定，快速迭代开发
- 高QPS，大容量存储，高可用

## 体系结构

| SQL概念       | MongoDB概念   | 解释                     |
| ----------- | ----------- | ---------------------- |
| database    | database    | 数据库                    |
| table       | collection  | 数据库表/集合                |
| row         | document    | 数据记录行/文档               |
| column      | field       | 数据字段/字段                |
| index       | index       | 索引                     |
| table joins |             | 表连接/MongoDB不支持表连接      |
|             | 嵌入文档        | MongoDB通过嵌入式文档代替多表连接   |
| primary key | primary key | 主键，MonoDB自动将_id字段设置为主键 |

MongoDB的最小存储单位就是文档document对象，对应于关系型数据库的行，以BSON的形式存储 （Binary-Json)在磁盘上。
BSON(Binary Serialized Document Format)是一种类json的二进制存储格式，支持内嵌的文档对象和数组对象，还有Json没有的数据类型如Data和Bin Data。BSON采用了类似于C语言结构体的名称、对表示方法，支持内嵌的文档对象，具有轻量性、可遍历性、高效性三个特点，能有效描述结构化和非结构化数据。优点是灵活性高，缺点是空间利用率不理想。

## 特点

- 高性能
	- MongoDB提高高性能的数据持久性，特别是对嵌入式数据模型的支持减少了数据库系统上的I/O活动。索引支持更快的查询，并且可用包含来自嵌入式文档和数组的键(文本索引解决搜索的需求、TTL索引解决历史数据自动过期的需求、地理位置索引可用于构建各种O2O应用)。mmapv1、 wiredtiger、 mongorocks（ rocks）、 In-memory等多引擎支持满足各种场景需求，Gridfs解决文件存储的需求。
- 高可用
	- MongoDB的复制工具称为副本集(replica set)，可提供自动故障转移和数据冗余
- 高扩展性
	- MongoDB提供了水平可扩展性作为核心功能的一部分
	- 分片将数据分布在一组集群的集群上，支持基于片键创建数据区域，在一个平衡的集群中，MongDB将一个区域所覆盖的读写只定向到该区域内的那些片
- 丰富查询
	- 支持丰富的查询语言，支持读和写操作
