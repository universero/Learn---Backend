## 概述

这门课涵盖了 OCaml 语言基础，数据结构和算法，测试开发，形式证明，语言特性实现等诸多内容。而且内容之间并不割裂，而是递进和互补，非常适合用来了解函数式编程.

## 环境

课程网站提供了线上的运行环境, 如果只是简单学习的话不需要自己再额外安装了.
如果希望能自己多实操下, 可以用docker安装镜像, 我用的是如下镜像
```bash
docker pull ocaml/opam:debian-11-ocaml-5.2
```
